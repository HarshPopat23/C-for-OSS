# Suggested Course Plan

This plan expands the syllabus into thirty sessions of approximately ninety minutes. It can be shortened by combining revision sessions.

| Session | Main work | Required output |
| --- | --- | --- |
| 1 | C purpose, history and program structure | Compile hello world |
| 2 | Standards, implementation and portability | Compare standard modes |
| 3 | System software and application software | Classify ten programs |
| 4 | Preprocessing, compilation, assembly and linking | Inspect intermediate files |
| 5 | Variables, identifiers, constants and input/output | Unit converter |
| 6 | Integer, floating and character types | Type inspection program |
| 7 | Scope, lifetime and storage classes | Counter demonstrations |
| 8 | Macros, headers and conditional compilation | Safe macro exercise |
| 9 | Operators, precedence and associativity | Expression evaluator |
| 10 | If, else, ladders and validation | Grade classifier |
| 11 | Switch and menus | Menu-driven calculator |
| 12 | For, while and do while | Number exercises |
| 13 | Nested loops, break and continue | Pattern and prime programs |
| 14 | Exit and structured alternatives to goto | Input validation lab |
| 15 | Function declarations, definitions and scope | Modular calculator |
| 16 | Parameters, return values and recursion | GCD and factorial |
| 17 | Command-line arguments | Command-line statistics |
| 18 | Call by value and pointer-based modification | Swap and update functions |
| 19 | One-dimensional and numeric arrays | Statistics program |
| 20 | Character arrays and safe string input | String inspection |
| 21 | String library and user-defined functions | Portable string toolkit |
| 22 | Two-dimensional and multidimensional arrays | Matrix operations |
| 23 | Pointer basics and pointer arithmetic | Array traversal |
| 24 | Character, double and array pointers | Token and table examples |
| 25 | Function pointers and returned pointers | Operation dispatcher |
| 26 | Structure pointers and arrays of pointers | Record sorting |
| 27 | Dynamic allocation and ownership | Dynamic integer list |
| 28 | Structures, unions and enumerations | Tagged record model |
| 29 | Text files, modes and EOF | File copy and report program |
| 30 | Integrated project and viva | Demonstration and review |

## Assessment suggestion

Use four components.

1. Weekly practice exercises for conceptual accuracy
2. Short debugging tasks for reading code
3. One closed-book practical examination
4. One integrated project with explanation and test cases

## Practice questions

1. Convert the plan into a fifteen-session plan without removing any syllabus topic.
2. Which sessions depend directly on earlier sessions?
3. Design a grading scheme totaling one hundred marks.
4. Create a checklist for evaluating the integrated project.
