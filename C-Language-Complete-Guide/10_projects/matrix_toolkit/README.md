# Project 4: Matrix Toolkit

This reference program demonstrates addition, transpose, and multiplication with fixed maximum dimensions and validated mathematical compatibility.

Compile and run:

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic matrix_toolkit.c -o matrix_toolkit
./matrix_toolkit
```

The sample matrices are embedded to keep the code focused on algorithms. Extend the program with safe input.

## Practice questions

1. Read dimensions and values from the user with a maximum of ten by ten.
2. Add subtraction and scalar multiplication.
3. Detect whether a square matrix is symmetric.
4. Compute main and secondary diagonal sums.
5. Use dynamic allocation to support dimensions chosen at run time.
6. Save and load matrices using a documented text format.
