# Integrated Projects

These projects combine the syllabus topics. Complete them in order. Read the project README, compile the supplied reference implementation, test it, and then extend it independently.

## Project map

| Project | Main concepts |
| --- | --- |
| Calculator | Functions, switch, validation, function pointers |
| Student records | Structures, strings, menus, files, parsing |
| Text analyzer | Command-line arguments, character functions, files |
| Matrix toolkit | Multidimensional arrays, nested loops, functions |

## Project-quality expectations

1. Compile with strict warnings.
2. Reject invalid input without undefined behavior.
3. Keep calculations separate from input and output when practical.
4. Check every resource acquisition.
5. Provide at least five test cases, including edge cases.
6. Explain data representation and algorithm choices.
7. Do not use removed or non-standard input functions.

## Practice questions

1. Which project best demonstrates every control statement?
2. Which project has persistent data and what can corrupt it?
3. Design a test plan for one project before reading its code.
4. Add one feature that requires dynamic memory.
5. Explain how each project could be divided into multiple source files and headers.
